# Настройка Yandex DataLens для Telegram Bot

## Описание интеграции

Проект предоставляет REST API endpoint'ы для визуализации данных о расходах в Yandex DataLens.

**Архитектура**: Локальная БД → PHP API → ngrok → DataLens

## Доступные API endpoint'ы

Все endpoint'ы доступны через: `http://localhost:8081/api.php?endpoint=<название>`

Или через ngrok: `https://your-ngrok-url/api.php?endpoint=<название>`

### 1. Все расходы
```
GET /api.php?endpoint=expenses
```
**Параметры (опционально)**:
- `start_date` - начальная дата (формат: Y-m-d, например: 2025-01-01)
- `end_date` - конечная дата (формат: Y-m-d)

**Возвращает**: Детальный список всех расходов с полями:
- `id` (integer) - ID записи
- `user_id` (integer) - ID пользователя
- `name` (string) - название траты
- `category` (string) - категория
- `amount` (float) - сумма
- `date` (datetime) - дата и время

### 2. Расходы по категориям (агрегация)
```
GET /api.php?endpoint=expenses-by-category
```
**Параметры (опционально)**:
- `start_date` - начальная дата
- `end_date` - конечная дата
- `user_id` - фильтр по пользователю

**Возвращает**: Суммы расходов по категориям с полями:
- `user_id` (integer)
- `category` (string)
- `total_amount` (float) - сумма всех расходов
- `count` (integer) - количество трат

### 3. Расходы по периодам
```
GET /api.php?endpoint=expenses-by-period
```
**Параметры**:
- `period` - тип периода: `day`, `week`, `month` (по умолчанию: month)
- `start_date` - начальная дата (опционально)
- `end_date` - конечная дата (опционально)
- `user_id` - фильтр по пользователю (опционально)

**Возвращает**: Расходы с группировкой по периодам:
- `user_id` (integer)
- `period` (string) - период (формат зависит от типа: 2025-10, 2025-42, 2025-10-11)
- `category` (string)
- `total_amount` (float)
- `count` (integer)

### 4. Лимиты
```
GET /api.php?endpoint=limits
```
**Параметры (опционально)**:
- `user_id` - фильтр по пользователю

**Возвращает**: Установленные лимиты:
- `user_id` (integer)
- `category` (string)
- `limit` (float)
- `updated_at` (datetime)

### 5. Сравнение расходов и лимитов
```
GET /api.php?endpoint=expenses-vs-limits
```
**Параметры (опционально)**:
- `start_date` - начальная дата (по умолчанию: начало месяца)
- `end_date` - конечная дата (по умолчанию: конец месяца)
- `user_id` - фильтр по пользователю

**Возвращает**: Сравнение факта и лимитов:
- `user_id` (integer)
- `category` (string)
- `total_amount` (float) - факт расходов
- `limit` (float) - установленный лимит
- `usage_percent` (float) - процент использования лимита
- `is_exceeded` (boolean) - превышен ли лимит

## Настройка безопасности (опционально)

### 1. Генерация API токена

Добавьте в файл `php/config.txt`:
```
DATALENS_API_TOKEN=ваш_случайный_токен_здесь
```

Для генерации токена можно использовать:
```bash
openssl rand -hex 32
```

### 2. Использование токена в DataLens

При настройке подключения в DataLens добавьте заголовок:
```
Authorization: Bearer ваш_токен_здесь
```

## Пошаговая настройка DataLens

### Шаг 1: Получение ngrok URL

1. Запустите проект: `start-docker.bat`
2. Откройте http://localhost:4040
3. Скопируйте HTTPS URL (например: `https://abc123.ngrok.io`)

### Шаг 2: Создание подключения в DataLens

1. Войдите в [Yandex DataLens](https://datalens.yandex.ru)
2. Нажмите **"Создать подключение"**
3. Выберите тип подключения: **"HTTP API"** или **"Generic HTTP"**
4. Заполните параметры:
   - **Название**: "Telegram Bot Expenses API"
   - **URL**: `https://your-ngrok-url/api.php`
   - **Метод**: GET
   - **Headers** (если используете токен):
     ```
     Authorization: Bearer ваш_токен
     ```

### Шаг 3: Создание датасетов

Создайте датасет для каждого endpoint'а:

#### Датасет 1: "Детальные расходы"
- **Подключение**: Telegram Bot Expenses API
- **URL параметры**: `?endpoint=expenses`
- **Поля датасета** (автоматически определятся):
  - id (Целое число)
  - user_id (Целое число)
  - name (Строка)
  - category (Строка)
  - amount (Дробное число)
  - date (Дата и время)

#### Датасет 2: "Расходы по категориям"
- **URL параметры**: `?endpoint=expenses-by-category`
- **Поля**:
  - user_id, category, total_amount, count

#### Датасет 3: "Расходы по периодам"
- **URL параметры**: `?endpoint=expenses-by-period&period=month`
- **Поля**:
  - user_id, period, category, total_amount, count

#### Датасет 4: "Лимиты"
- **URL параметры**: `?endpoint=limits`

#### Датасет 5: "Расходы vs Лимиты"
- **URL параметры**: `?endpoint=expenses-vs-limits`

### Шаг 4: Создание дашборда

1. Нажмите **"Создать чарт"**
2. Выберите датасет
3. Создайте визуализации:

#### Пример 1: Круговая диаграмма по категориям
- **Тип**: Круговая диаграмма
- **Датасет**: "Расходы по категориям"
- **Цвет**: category
- **Мера**: SUM(total_amount)

#### Пример 2: Столбчатая диаграмма динамики
- **Тип**: Столбчатая диаграмма
- **Датасет**: "Расходы по периодам"
- **X**: period
- **Y**: SUM(total_amount)
- **Цвет**: category

#### Пример 3: Таблица детальных расходов
- **Тип**: Таблица
- **Датасет**: "Детальные расходы"
- **Столбцы**: date, name, category, amount
- **Сортировка**: date DESC

#### Пример 4: Индикатор превышения лимитов
- **Тип**: Индикатор
- **Датасет**: "Расходы vs Лимиты"
- **Мера**: COUNT(is_exceeded = true)
- **Цвет**: Красный при значении > 0

#### Пример 5: График факт vs лимит
- **Тип**: Столбчатая диаграмма с несколькими осями
- **Датасет**: "Расходы vs Лимиты"
- **X**: category
- **Y1**: total_amount
- **Y2**: limit

4. Соберите все чарты на дашборде
5. Добавьте фильтры:
   - Фильтр по дате
   - Фильтр по категории
   - Фильтр по пользователю (если несколько пользователей)

## Примеры запросов для тестирования

### Тест локально:
```bash
# Все расходы
curl "http://localhost:8081/api.php?endpoint=expenses"

# Расходы по категориям за октябрь
curl "http://localhost:8081/api.php?endpoint=expenses-by-category&start_date=2025-10-01&end_date=2025-10-31"

# Расходы по дням
curl "http://localhost:8081/api.php?endpoint=expenses-by-period&period=day"
```

### Тест через ngrok:
```bash
curl "https://your-ngrok-url/api.php?endpoint=expenses"
```

### С токеном:
```bash
curl -H "Authorization: Bearer your_token" \
     "https://your-ngrok-url/api.php?endpoint=expenses"
```

## Возможные проблемы и решения

### Проблема 1: DataLens не может подключиться
**Решение**:
- Проверьте, что ngrok запущен: http://localhost:4040
- Проверьте URL в настройках подключения DataLens
- Убедитесь, что используете HTTPS URL от ngrok

### Проблема 2: Ошибка 401 Unauthorized
**Решение**:
- Проверьте токен в `config.txt`
- Проверьте заголовок Authorization в DataLens
- Или отключите проверку токена (удалите DATALENS_API_TOKEN из config.txt)

### Проблема 3: Пустые данные
**Решение**:
- Убедитесь, что в БД есть данные (добавьте траты через бота)
- Проверьте фильтры по датам
- Проверьте endpoint напрямую через curl

### Проблема 4: Ngrok URL изменился
**Решение**:
- При каждом перезапуске ngrok генерирует новый URL
- Обновите URL в настройках подключения DataLens
- Для постоянного URL используйте платную версию ngrok

## Рекомендации

1. **Для продакшена**: Разверните проект на сервере с постоянным доменом вместо ngrok
2. **Безопасность**: Всегда используйте токен авторизации для публичных endpoint'ов
3. **Производительность**: Добавьте индексы в БД на поля `user_id`, `ts`, `category`
4. **Кэширование**: Для больших объемов данных добавьте кэширование результатов
5. **Лимиты**: Настройте rate limiting для защиты от перегрузки

## Дополнительные возможности

### Добавление вычисляемых полей в DataLens

В датасетах можно создать вычисляемые поля:
- **Год-месяц**: `DATE_FORMAT([date], '%Y-%m')`
- **Название месяца**: `DATE_FORMAT([date], '%B %Y')`
- **День недели**: `DAYNAME([date])`
- **Процент от общего**: `[amount] / SUM([amount]) * 100`

### Настройка обновления данных

DataLens обновляет данные при каждом запросе к API. Для контроля частоты обновлений:
1. Настройте автообновление дашборда (10 сек, 30 сек, 1 мин и т.д.)
2. Добавьте кнопку "Обновить" на дашборд

## Контакты и поддержка

Если возникли проблемы с настройкой, проверьте:
- Логи контейнера PHP: `docker logs php-bot`
- Логи ngrok: http://localhost:4040/inspect/http
- Статус API: `curl http://localhost:8081/api.php?endpoint=expenses`
