# Решения

## 2026-09-27 — в общий словарь только системные категории

`CategoryHint::remember()` пишет в `user_id = 0` лишь категорию, которая есть
в `categories` с `user_id = 0`; своя категория книги остаётся в личном словаре.

- Почему: общий словарь читают все книги, а своя категория есть у одной —
  остальные подсказку отбрасывают, а их прежняя подсказка уже затёрта.
- Отвергнуто: фильтровать при чтении (`find()` пропускает чужие категории) —
  прежнюю системную подсказку это не вернуло бы, её к тому моменту уже перезаписали.
- Уже испорченные записи удаляет миграция 007.
